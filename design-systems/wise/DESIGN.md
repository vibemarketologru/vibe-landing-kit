# Wise

> Описание эстетики по открытым материалам. Проект не аффилирован с Wise; товарные знаки принадлежат их владельцам. Логотипы и фирменные шрифты не используются.

Сверхжирные заголовки в 900-м начертании, одна лаймовая кнопка-пилюля и шалфейно-серый фон, на котором лежат белые карточки со скруглением 24 px. Глубину даёт смена поверхностей, а не тени; цены показаны честной таблицей сравнения. Читается как спокойный скандинавский журнал о деньгах, а не как банк.

**Подходит:** финтех и переводы денег, платёжные и банковские сервисы, бухгалтерия и налоги, страхование, SaaS для малого бизнеса, услуги с прозрачной ценой. **Цели:** заявки, расчёт стоимости, доверие через прозрачные цены, регистрация, запись на консультацию. **Настроение:** дружелюбный, прозрачный, уверенный, светлый, журнальный.

## Раскладка лендинга

Полоса во всю ширину цвета background (шалфей). Раскладка 7/5. Слева: бейдж-надзаголовок, заголовок display в 2–3 строки, лид 20px цвета text_muted, строка доверия caption (цифра клиентов, срок ответа) и при необходимости контурная кнопка button_tertiary («Как считаем цену»). Справа calc_card: короткий калькулятор выгоды с лаймовой кнопкой «Получить расчёт» или сразу форма заявки из двух полей — в ней единственная лаймовая пилюля первого экрана. Фото людей не нужны: вместо них цифры, иллюстрации SVG и макеты продукта внутри карточек.

Порядок секций: nav → hero → proof_bar → benefits → how → numbers → compare → testimonials → pricing → faq → lead_form → footer

Всё в одну колонку, поля 16px. Первый экран: бейдж → заголовок 36px → лид → строка доверия → calc_card во всю ширину, её лаймовая кнопка 52px во всю ширину карточки. Полосы 48px сверху и снизу. Цифры stat по две в ряд, длинные числа — по одной. Таблица сравнения превращается в карточки «мы / альтернатива» без горизонтальной прокрутки. Когда кнопка calc_card уходит с экрана, появляется липкая лаймовая кнопка заявки. Проверка — экран 360px: ни одно слово заголовка не выходит за край.

## Форма заявки

Форма живёт в calc_card: белая карточка с рамкой 1px цвета text и скруглением 24px. Подписи 14px 600 над полями, поля 56px с рамкой 1px text и скруглением 12px, между полями 16px. Кнопка — лаймовая пилюля 52px во всю ширину карточки с глаголом результата («Получить расчёт»), под ней строка caption: срок ответа и что не будет спама. Поля: name, phone. Согласие 152-ФЗ: да.

## Делать

- Одна лаймовая пилюля на экран — главное действие; на первом экране она живёт в calc_card, слева только строка доверия и при необходимости контурная кнопка.
- Заголовки только Inter Tight 900 в обычном регистре с интерлиньяжем 0.95–1.0; остальной текст — Inter 400/600.
- Скругление 24px у кнопок и карточек, 12px у полей; острых углов в интерфейсе нет.
- Чередуйте полосы: шалфейная с белыми карточками, белая с шалфейными — глубина из смены поверхностей, без теней.
- Покажите цену честно: таблица сравнения с альтернативами, у каждой цифры — источник и дата замера.
- Делайте цифры героями: срок, экономия и цена — Inter Tight 900 с табличными цифрами, крупнее окружающего текста.
- Проверяйте заголовок на экране 360px и в колонке 7/12: слово из 13–15 букв — масштаб l (64/32px), слово длиннее — переписать, а не переносить посреди слова.

## Не делать

- Не добавлять второй яркий акцент: персиковый #ffc091 и голубой #38c8ff из палитры бренда — только внутри иллюстраций.
- Не ставить лаймовую кнопку на зелёный фон (включая tint) и не писать лаймовым текстом по белому или шалфейному — 1.2–1.5:1.
- Не набирать заголовки тоньше 900 и не заменять их нейтральным гротеском среднего веса.
- Не использовать серый #868685 для текста — только для контуров; текст ошибки — error (#a72027, в тёмной теме #f2777b), яркий #d03238 — только для значков.
- Не превращать зелёный бренда в цвет успеха: для статусов — отдельные success и error.
- Не ставить на первый экран фото людей и сток: вместо них цифры, калькулятор и макет продукта.
- Не прятать согласие на обработку данных в предотмеченную галочку.

## Медиа

**Первый экран.** Яркое поле, крупный простой заголовок, фото реального клиента или флаги/иллюстрации.

**Видео ниже.** Короткое объясняющее видео с субтитрами по кнопке.

**Картинки.** Реальные люди, яркие плоские иллюстрации, прозрачные цифры.

**Персонаж или маскот.** Реальные клиенты в историях.

**Аудиоверсия.** Аудиоверсия объяснения условий уместна.

**Избегать:** мрачные тона; мелкий шрифт в условиях.
