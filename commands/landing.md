Собери рекламный лендинг для A/B-теста по навыку landing-ab.

Бриф: $ARGUMENTS

Иди по маршруту навыка: стиль (design_systems → get_design_system) → семантика (build_semantics, сначала назови цену) → анимации (get_motion_recipe) → вёрстка варианта А → вариант Б с одним отличием → чек-лист качества. В конце — короткий отчёт: гипотеза, отличие А и Б, потраченная сумма, следующие шаги.
