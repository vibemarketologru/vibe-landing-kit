# Шаблоны к навыку landing-law-ru

Это не юридическая консультация: шаблоны закрывают типовой лендинг с формой «имя + телефон».
Всё в квадратных скобках заполняется данными клиента. **Страница со скобками не запускается**, а
реквизиты не придумываются: нет данных — спросить клиента.

## 1. Форма заявки с согласием

Проверено в Chromium 24.09.2026: галочки не отмечены по умолчанию; без имени, телефона или согласия
заявка не уходит, а человек видит причину текстом; при сбое сервера введённое не стирается.

```html
<section id="contacts">
<form data-lead-form novalidate>
  <label>Как к вам обращаться <input type="text" name="name" required autocomplete="name"></label>
  <label>Телефон <input type="tel" name="phone" required autocomplete="tel" inputmode="tel"></label>

  <label class="consent">
    <input type="checkbox" name="consent" value="1">
    <span>Даю <a href="/soglasie" target="_blank">согласие на обработку персональных данных</a>
      для ответа на заявку. <a href="/politika" target="_blank">Политика обработки персональных данных</a></span>
  </label>
  <label class="consent">
    <input type="checkbox" name="marketing" value="1">
    <span>Хочу получать новости и предложения (необязательно)</span>
  </label>

  <input type="hidden" name="consent_version" value="2026-09-24">
  <input type="hidden" name="ab_variant">
  <button type="submit">Записаться на бесплатный замер</button>
  <p class="form-status" role="status" aria-live="polite"></p>
</form>
</section>
<script>
document.addEventListener('submit', function (e) {
  var form = e.target.closest('form[data-lead-form]');
  if (!form) return;
  e.preventDefault();
  var status = form.querySelector('.form-status');
  var btn = form.querySelector('button[type="submit"]');
  if (form.dataset.sending === '1') return;                        // повторный клик во время отправки
  if (!form.elements['name'].value.trim() || !form.elements['phone'].value.trim()) {
    status.textContent = 'Укажите имя и телефон, чтобы мы могли перезвонить.'; return;
  }
  if (!form.elements['consent'].checked) {
    status.textContent = 'Отметьте согласие на обработку данных, чтобы мы могли с вами связаться.'; return;
  }
  form.dataset.sending = '1'; btn.textContent = 'Отправляем…'; status.textContent = '';
  var data = Object.fromEntries(new FormData(form));
  data.page_url = location.href;                                   // время, IP и браузер фиксирует сервер
  fetch('/api/lead', { method: 'POST', headers: { 'Content-Type': 'application/json', 'Accept': 'application/json' }, body: JSON.stringify(data) })
    .then(function (r) { if (!r.ok) throw new Error(r.status); return r.json(); })
    .then(function () { form.reset(); status.textContent = 'Заявка принята. [Когда и как свяжемся — из брифа].'; if (window.onLeadSent) onLeadSent(); })
    .catch(function () { status.textContent = 'Не получилось отправить. Попробуйте ещё раз или позвоните нам — введённое сохранено.'; })
    .finally(function () { form.dataset.sending = ''; btn.textContent = 'Записаться на бесплатный замер'; });
}, true);
</script>
```

- `/api/lead` — ваш приёмник. Он сначала **записывает заявку в базу**, потом доставляет её (CRM,
  мессенджер, почта). Ответ — JSON, а не перенаправление на страницу.
- В запись о согласии сервер добавляет сам: время, IP, `User-Agent`; из формы берёт `page_url` и
  `consent_version`. Меняете текст согласия — меняйте версию.
- Не отправлять заявки на сторонние сервисы форм и в `mailto:`, не показывать `alert()`.
- Ловушка для ботов (скрытое поле) **помечает** заявку как подозрительную, но не выбрасывает её, если
  имя и телефон заполнены: браузеры с автозаполнением сами вписывают туда значения живых людей.
- `ab_variant` заполняет скрипт сплита (`hypothesis-lab/snippets.md`).

## 2. Согласие на обработку персональных данных (отдельная страница `/soglasie`)

```
СОГЛАСИЕ НА ОБРАБОТКУ ПЕРСОНАЛЬНЫХ ДАННЫХ
(версия [ГГГГ-ММ-ДД])

Отправляя заявку на странице [адрес сайта], я свободно, своей волей и в своём интересе даю согласие
[ОПЕРАТОР: полное наименование или ФИО ИП, ИНН, ОГРН/ОГРНИП, адрес — из документов клиента] на
обработку моих персональных данных: имени и номера телефона [и адреса электронной почты, если есть
такое поле].

Цель обработки: связаться со мной и ответить на мою заявку [уточнить: рассчитать стоимость,
записать на замер / консультацию].

Действия с данными: сбор, запись, систематизация, хранение, уточнение, использование, передача
[кому: название CRM-сервиса, сервиса телефонии — с указанием, что серверы в РФ], удаление.
Обработка — с использованием средств автоматизации и без них.

Срок: до достижения цели обработки или до отзыва согласия [или конкретный срок].

Согласие можно отозвать в любой момент, написав на [почта] или [адрес]. После отзыва данные
удаляются в срок, установленный законом.
```

Согласие на рассылку — отдельный такой же документ со своей целью («получать новости и предложения»)
и своей галочкой.

## 3. Короткий раздел политики на странице (4–6 предложений)

Ставится последней секцией перед подвалом, мелким спокойным текстом, `id="privacy"`.

```html
<section id="privacy">
  <h2>Политика обработки персональных данных</h2>
  <p>Оператор персональных данных — [название бизнеса из брифа; реквизиты — только из документов клиента].
  Мы обрабатываем имя и телефон, которые вы оставили в форме, чтобы связаться с вами и ответить на
  заявку. Данные хранятся [на серверах в России] до достижения этой цели или до отзыва согласия.
  Мы передаём их только [сервисам, через которые обрабатываем заявки: CRM, телефония] и не продаём
  третьим лицам. Отозвать согласие и попросить удалить данные можно по контактам на этой странице.
  Полный текст — <a href="/politika">Политика обработки персональных данных</a>.</p>
</section>
```

Не писать: выдуманное ООО, ИНН «0000000000», чужой адрес, «данные надёжно защищены по стандарту …»
без подтверждения.

## 4. Полная политика `/politika`: скелет разделов

Наполнение — по данным клиента и с юристом; перечень ориентирован на ст. 18.1 152-ФЗ
(проверить на дату запуска по разъяснениям Роскомнадзора).

1. Общие положения: кто оператор, реквизиты, контакт для обращений.
2. Какие данные обрабатываются и чьи (посетители сайта, заявители).
3. Цели обработки — каждая отдельно, для каждой — состав данных.
4. Правовые основания (согласие, договор).
5. Действия с данными и способы обработки.
6. Кому передаются: сервисы заявок, CRM, телефония, почта, аналитика (включая Яндекс Метрику и cookie).
7. Где хранятся (Россия) и сколько.
8. Права человека: узнать, уточнить, отозвать согласие, потребовать удаления; как это сделать.
9. Меры защиты.
10. Дата и версия политики.

## 5. Готовые строки предупреждений

| Где | Текст | Размер |
|---|---|---|
| Медицина, баннер и страница | «Имеются противопоказания. Необходима консультация специалиста» (фиксированной формулировки закон не задаёт) | не меньше 5 % рекламной площади |
| Медицина, объявления Директа | «Есть противопоказания. Посоветуйтесь с врачом» — в текстовых добавляется само, в графике и видео — вручную | по справке Директа |
| Медицина, подвал | «[Наименование организации], лицензия № [номер] от [дата], выдана [кем]» | читаемым текстом |
| Потребкредит, заём | «Оценивайте свои финансовые возможности и риски» | не меньше 5 % рекламной площади |
| Потребкредит с условиями, влияющими на ПСК | «Изучите все условия кредита (займа)» + ссылка на условия | по ч. 2.1 ст. 28 |
| Кредит со ставкой | диапазон полной стоимости кредита, шрифтом не меньше ставки | по ч. 3 ст. 28 |
| Финансовая услуга | наименование банка или МФО, оказывающего услугу | по ч. 1 ст. 28 |

## 6. Проверка перед запуском (5 минут)

- [ ] Открыть страницу в чистом окне: обе галочки пустые.
- [ ] Нажать кнопку без галочки: виден текст причины, заявка не ушла, поля не стёрлись.
- [ ] Отправить проверочную заявку: она есть в базе вместе со временем, IP, браузером, адресом
      страницы и версией согласия; дошла до получателя.
- [ ] Ссылки «Согласие» и «Политика» открываются, в них нет скобок-заглушек и выдуманных реквизитов.
- [ ] Уведомление в Роскомнадзор подано (номер в реестре операторов записан).
- [ ] Для медицины и финансов — строки из раздела 5 на месте, лицензия совпадает с сайтом.
- [ ] Нет всплывающих окон на входе и уходе; сплит без JS-редиректа, если идёт трафик из ВК.
