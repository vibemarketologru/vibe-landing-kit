# Шаблоны к навыку landing-brief

## 1. Факты владельца (заполнить до брифа)

Всё, что не записано здесь, на странице не появляется. Пустая строка — нормально: для неё есть
замена в правилах честности (`SKILL.md`).

| Факт | Значение | Подтверждено кем и чем |
|---|---|---|
| Название бизнеса | | |
| Город, район, адрес | | |
| Что продаём (услуга, товар, пакет) | | |
| Цены или «от» | | |
| Сроки | | |
| Гарантия и её условия | | |
| Бесплатный первый шаг (замер, осмотр, консультация) | | |
| Годы работы | | |
| Команда (сколько, кто) | | |
| Отзывы (где лежат, можно ли показывать с именами) | | |
| Кейсы с цифрами | | |
| Партнёры и клиенты-бренды (с разрешением на логотип) | | |
| Лицензии, сертификаты, номера | | |
| Телефон, мессенджеры, почта | | |
| Реальный дедлайн или лимит акции | | |
| Цель страницы (какую заявку ждём) | | |
| Куда уходят заявки | | |

## 2. Разведка рынка (ответ агента с веб-поиском)

```json
{
  "competitors": [
    {
      "name": "как называется",
      "url": "адрес",
      "offer": "что обещают на первом экране",
      "prices": "цены, если открыты",
      "guarantee": "гарантия",
      "proof": "какие доказательства показывают",
      "cta": "текст главной кнопки",
      "weak_spot": "чего не хватает или что раздражает"
    }
  ],
  "market_cliches": ["фразы, с которых начинают почти все"],
  "gaps": ["что никто не обещает, хотя покупателю это важно"],
  "buyer_phrases": ["кухни на заказ", "кухня на заказ цена", "кухни на заказ недорого"]
}
```

3–5 конкурентов, только реальные, со ссылками. `buyer_phrases` — 3–4 фразы, первая — сама ниша;
их частотность проверяется в Вордстате, а не угадывается.

## 3. Бриф A–G (600–900 слов, нумерованный текст)

```
A. АУДИТОРИЯ И ТРАФИК
Кто покупает: …
Уровень осведомлённости (Шварц): не знает о проблеме / знает о проблеме / знает о решениях / знает о продукте / готов купить — …
Трафик: откуда и какой температуры — …
Вывод: сколько объяснять до просьбы — …

B. ОФФЕР
Результат: …   Для кого: …   Срок / цена: …
Отличие от конкурентов (по разведке): …
Снятие риска: …
Текст главной кнопки (первый лёгкий шаг): «…»

C. ЗАГОЛОВОК
H1: «…» (фраза спроса: «…», показов в месяц: …)
Подстрока: «…» (снимает сомнение: …)
Чипы-доказательства первого экрана: 1) … 2) … 3) …

D. ВОЗРАЖЕНИЯ
1. «…» — ответ: …
(4–7 пунктов)

E. МОДЕЛЬ УБЕЖДЕНИЯ
… — потому что …

F. ПЛАН СЕКЦИЙ
1. Первый экран — задача: … — раскладка: … — фон: … — ключевая строка: «…»

G. АРТ-ДИРЕКЦИЯ
Зерно: экран №…, мотив №…, тема … — принято / заменено на …, потому что …

Основа темы: светлая / тёмная / смешанная
Палитра: фон #…, поверхность #…, текст #…, акцент #…, второй акцент #…
Типографика: …
Композиция первого экрана: …
Фирменный мотив: …
Фото: …
```

## 4. Пример заполненного брифа (факты условные)

```
A. Владельцы квартир в новостройках Казани 28–45 лет, делают ремонт впервые. Уровень — «знает о
решениях»: сравнивают фабрики и частных мастеров. Трафик — поиск Директа «кухни на заказ казань»,
тёплый. Объяснять много не нужно, нужно показать отличие.
B. Кухня по вашим размерам с монтажом за 21 день после замера — для тех, кто въезжает в новостройку.
Отличие: у конкурентов из разведки срок «от 30 дней» или не назван. Снятие риска: фиксированная
цена в договоре после замера. Кнопка: «Записаться на бесплатный замер».
C. H1: «Кухни на заказ в Казани с монтажом за 21 день» (группа спроса «кухни на заказ в Казани» —
1 101 показ в месяц по Вордстату). Подстрока: «Цена в договоре не меняется после замера». Чипы: «с 2019 года»,
«замер бесплатно», «гарантия 2 года».
D. 1) «Сорвёте сроки» — неустойка за день просрочки в договоре. 2) «Дорого» — три пакета, цена «от»
на первом экране. 3) «Не влезет техника» — дизайнер на замере сразу расставляет технику. 4) «А если
не понравится» — 3D-проект до оплаты.
E. Сравнение-first: аудитория выбирает между фабрикой и мастером, главный аргумент — срок.
F. 1 Первый экран — разделённый, фото кухни в новостройке. 2 Полоса-заявление «21 день — от замера
до готовой кухни». 3 Таблица «мы против обычного подхода». 4 Вертикальный степпер «как проходит
21 день». 5 Три тарифа. 6 Карточки возражений. 7 Блок гарантии. 8 FAQ-аккордеон. 9 Контакты с
формой → политика → подвал.
G. Зерно: экран 1, мотив 6 («техпаспорт»), тема светлая — принято: сроки и размеры хорошо
показывать таблицами. Палитра: фон #F7F5F0, поверхность #FFFFFF, текст #1C1B19, акцент #1F5C4A,
второй акцент #C8A45A. Мотив: тонкие размерные линии у фото и таблиц.
```

## 5. Промпт ревью (для отдельного агента)

```
Ты — старший ревьюер рекламных лендингов. Тебе дают бриф, список подтверждённых фактов владельца и
HTML страницы. Проверь страницу по 14 пунктам:
1 документ и внешние хосты; 2 медиа; 3 адаптив 360/390/768/1280; 4 пустые места и заглушки;
5 уровень дизайна и отличимость для ниши; 6 движение и reduced-motion; 7 SEO; 8 маркетинг над сгибом;
9 вёрстка и контраст; 10 ПРАВДА в обе стороны (выдумки против фактов и потерянные факты, ослабляющие
оговорки); 11 ФОРМА (одна, имя+телефон, галочка согласия не отмечена заранее и ведёт на политику,
реальная отправка, политика на странице, все кнопки к форме); 12 шрифты без внешних хостов;
13 performance-маркетинг (тест 5 секунд, кнопка каждые 1,5–2 экрана, возражения, снятие риска у
формы, липкая кнопка на телефоне, слабые тексты кнопок); 14 шаблонность (соседние раскладки,
«тёмный стеклянный SaaS», «сетка преимуществ + статистика + отзывы»; назови секции и как пересобрать).
Каждый пункт — «где → что не так → как исправить», короче 25 слов. Не больше 12 проблем и 8 улучшений.
Сначала блокирующие (10, 11). Верни ТОЛЬКО JSON без markdown:
{"issues": ["…"], "improvements": ["…"]}
```
